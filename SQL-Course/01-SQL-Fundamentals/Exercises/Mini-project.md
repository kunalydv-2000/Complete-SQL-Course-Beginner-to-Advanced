# Mini Project

## Employee Management System

Create a simple Employee Management System database.

---

## Requirements

### Table 1: Departments

| Column |
|----------|
| DepartmentID |
| DepartmentName |

---

### Table 2: Employees

| Column |
|----------|
| EmployeeID |
| EmployeeName |
| Age |
| Salary |
| DepartmentID |

---

## Tasks

### Step 1

Create both tables.

---

### Step 2

Insert:

#### Departments

| DepartmentID | DepartmentName |
|--------------|----------------|
| 1 | HR |
| 2 | IT |
| 3 | Finance |

---

#### Employees

Insert at least:

```text
5 Employees
```

---

### Step 3

Write queries to:

1. Display all employees.
2. Display all departments.
3. Display employees earning more than 50000.
4. Count total employees.
5. Find highest salary.
6. Find average salary.

---

### Step 4

Update one employee salary.

---

### Step 5

Delete one employee.

---

- ALTER
