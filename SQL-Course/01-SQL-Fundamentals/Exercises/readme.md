# Module 01 Exercises

This folder contains exercises for SQL Fundamentals.

## Exercise Structure

### Theory Questions
Test conceptual understanding of:

- Databases
- DBMS
- RDBMS
- SQL
- Keys
- SQL Commands

### Practical Assignment
Practice:

- CREATE
- INSERT
- SELECT
- UPDATE
- DELETE

### Mini Project
Apply all concepts learned in this module.

## Submission Guidelines

1. Attempt theory questions without notes.
2. Complete practical exercises using SQL.
3. Build the mini project database.
4. Compare solutions only after completion.
