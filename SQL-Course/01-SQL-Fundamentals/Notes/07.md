# Database Terminology

## Database

A collection of related data.

Example:

```text
CompanyDB
```

## Table

A collection of rows and columns.

Example:

```text
Employees
```

## Row (Record)

A single entry in a table.

## Column (Field)

A specific attribute in a table.

## Schema

The blueprint of a database.

Contains:

- Tables
- Columns
- Data Types
- Relationships

## Primary Key

Uniquely identifies each row.

Rules:

- Cannot repeat
- Cannot be NULL

## Foreign Key

Creates relationships between tables.
