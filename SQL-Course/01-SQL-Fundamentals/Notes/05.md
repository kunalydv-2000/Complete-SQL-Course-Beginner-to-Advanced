# What is SQL?

SQL stands for Structured Query Language.

It is the standard language used to communicate with relational databases.

## SQL Capabilities

SQL allows users to:

- Create tables
- Insert data
- Retrieve data
- Update data
- Delete data

## Example Query

```sql
SELECT *
FROM Employees;
```

### Output

| EmployeeID | Name |
|------------|------|
| 101 | Kunal |
| 102 | Rahul |
```
