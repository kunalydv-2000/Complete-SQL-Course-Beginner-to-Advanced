# RDBMS

RDBMS stands for Relational Database Management System.

An RDBMS stores data in tables and supports relationships between tables.

## Example

### Employees

| EmployeeID | Name |
|------------|------|
| 101 | Kunal |
| 102 | Rahul |

### Departments

| DepartmentID | DepartmentName |
|--------------|----------------|
| 1 | HR |
| 2 | IT |

## Key Features

### Tables

Data is stored in rows and columns.

### Relationships

Tables can be connected.

### Primary Keys

Uniquely identify records.

### Foreign Keys

Create relationships between tables.
