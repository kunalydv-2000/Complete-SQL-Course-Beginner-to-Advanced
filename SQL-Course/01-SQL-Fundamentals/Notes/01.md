# What is Data?

Data refers to raw facts, observations, or information.

## Example

| EmployeeID | Name | Salary |
|------------|------|---------|
| 101 | Kunal | 45000 |
| 102 | Rahul | 50000 |
| 103 | Aman | 55000 |

In this table:

- Employee IDs are data
- Names are data
- Salaries are data

## Key Points

- Data is the foundation of information systems.
- Raw data becomes meaningful after processing.
- Organizations use data for decision-making.
