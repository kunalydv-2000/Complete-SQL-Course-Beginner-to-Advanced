Instead of manually:

```text id="ba003"

Calculating KPIs
```

# Automation Scenario 1

## Book Catalog Reporting System

Business Requirement:

```text id="ba009"
Generate Book Catalog Reports
```

---

# Step 1: Create View

```sql id="ba010"
CREATE VIEW vw_BookCatalog
AS
SELECT
    B.BookID,
    B.Title,
    C.CategoryName,
    P.PublisherName,
    B.BookPrice
FROM Books B
INNER JOIN Categories C
    ON B.CategoryID = C.CategoryID
INNER JOIN Publishers P
    ON B.PublisherID = P.PublisherID;
```

---

# Step 2: Create Procedure

```sql id="ba011"
CREATE PROCEDURE GetBookCatalog
AS
BEGIN

    SELECT *
    FROM vw_BookCatalog;

END;
```

---

# Step 3: Execute

```sql id="ba012"
EXEC GetBookCatalog;
```

---

Business users no longer need complex joins.

# Automation Scenario 3

## Inventory KPI Dashboard

Management wants:

```text id="ba016"
Total Books

Inventory Value

Average Price

Highest Price

Lowest Price
```

---

# Procedure

```sql id="ba017"
CREATE PROCEDURE GetInventoryKPIs
AS
BEGIN

    SELECT
        COUNT(*) AS TotalBooks,
        SUM(BookPrice) AS InventoryValue,
        AVG(BookPrice) AS AveragePrice,
        MAX(BookPrice) AS HighestPrice,
        MIN(BookPrice) AS LowestPrice
    FROM Books;

END;
```

---

# Execute

```sql id="ba018"
EXEC GetInventoryKPIs;
```

---

# Automation Scenario 4

## Executive Dashboard

Management wants one-click KPI reporting.

---

# Procedure

```sql id="ba019"
CREATE PROCEDURE GetExecutiveDashboard
AS
BEGIN

    SELECT
        (SELECT COUNT(*) FROM Books) AS TotalBooks,
        (SELECT COUNT(*) FROM Members) AS TotalMembers,
        (SELECT COUNT(*) FROM Authors) AS TotalAuthors,
        (SELECT COUNT(*) FROM Publishers) AS TotalPublishers,
        (SELECT COUNT(*) FROM Reservations) AS TotalReservations,
        (SELECT COUNT(*) FROM BorrowRecords) AS TotalBorrows;

END;
```

---

# Execute

```sql id="ba020"
EXEC GetExecutiveDashboard;
```

# Automation Scenario 5

## Parameterized Reporting

Business users need category-specific reports.

---

# Procedure

```sql id="ba021"
CREATE PROCEDURE GetBooksByCategory
    @CategoryID INT
AS
BEGIN

    SELECT
        BookID,
        Title,
        BookPrice
    FROM Books
    WHERE CategoryID = @CategoryID;

END;
```

---

# Execute

```sql id="ba022"
EXEC GetBooksByCategory
    @CategoryID = 2;
```

# Automation Scenario 6

## KPI Output Procedure

---

Procedure:

```sql id="ba023"
CREATE PROCEDURE GetTotalBooks
    @TotalBooks INT OUTPUT
AS
BEGIN

    SELECT
        @TotalBooks = COUNT(*)
    FROM Books;

END;
```

---

Execute:

```sql id="ba024"
DECLARE @Count INT;

EXEC GetTotalBooks
    @TotalBooks = @Count OUTPUT;

SELECT @Count;
```

# Automation Scenario 7

## Dynamic Search System

---

Procedure:

```sql id="ba025"
CREATE PROCEDURE SearchBooks
    @Keyword VARCHAR(100)
AS
BEGIN

    DECLARE @SQL NVARCHAR(MAX);

    SET @SQL =
    N'SELECT *
      FROM Books
      WHERE Title LIKE ''%' +
      @Keyword +
      '%''';

    EXEC(@SQL);

END;
```

---

Execute:

```sql id="ba026"
EXEC SearchBooks
    @Keyword = 'SQL';
```
