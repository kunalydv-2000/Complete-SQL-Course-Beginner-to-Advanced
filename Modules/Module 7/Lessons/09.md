# What is Dynamic SQL?

Dynamic SQL is SQL code generated and executed at runtime.

Instead of writing:

```sql id="ds005"
SELECT *
FROM Books;
```

you create the query as text:

```sql id="ds006"
'SELECT * FROM Books'
```

and execute it later.

# Example 3: Dynamic Category Search

```sql id="ds014"
DECLARE @CategoryID INT = 1;
DECLARE @SQL VARCHAR(MAX);

SET @SQL =
'SELECT *
 FROM Books
 WHERE CategoryID = '
+ CAST(@CategoryID AS VARCHAR);

EXEC(@SQL);
```

---

Generated SQL:

```sql id="ds015"
SELECT *
FROM Books
WHERE CategoryID = 1;
```

# Method 2: sp_executesql

Recommended Dynamic SQL technique.

---

# Syntax

```sql id="ds018"
EXEC sp_executesql
    @SQL,
    @ParameterDefinition,
    ParameterValues;
```

---

# Example 4: Parameterized Dynamic SQL

```sql id="ds019"
DECLARE @SQL NVARCHAR(MAX);

SET @SQL =
N'SELECT *
  FROM Books
  WHERE CategoryID = @CategoryID';

EXEC sp_executesql
    @SQL,
    N'@CategoryID INT',
    @CategoryID = 1;
```

---

Benefits:

```text id="ds020"
Safer

Reusable

More Efficient
```

# Example 6: Dynamic Sorting

Business Requirement:

```text id="ds022"

Sorting Column
```

---

Procedure:

```sql id="ds023"
CREATE PROCEDURE GetBooksSorted
    @SortColumn VARCHAR(50)
AS
BEGIN

    DECLARE @SQL NVARCHAR(MAX);

    SET @SQL =

      FROM Books
      ORDER BY ' + @SortColumn;

    EXEC(@SQL);

END;
```

```sql id="ds024"
EXEC GetBooksSorted
```

# SQL Injection

Dynamic SQL introduces security concerns.

---

# Dangerous Example

```sql id="ds028"
SET @SQL =
'SELECT *
 FROM Books
 WHERE Title = '''
+ @Title + '''';
```

---

User Input:

```text id="ds029"
'; DROP TABLE Books; --
```

---

Generated SQL:

```sql id="ds030"
SELECT *
FROM Books
WHERE Title='';

DROP TABLE Books;
```

---

Potential Result:

```text id="ds031"
Data Loss
```

---

# Preventing SQL Injection

Use:

```text id="ds032"
sp_executesql

Parameterized Queries
```

---

Example:

```sql id="ds033"
DECLARE @SQL NVARCHAR(MAX);

SET @SQL =
N'SELECT *
  FROM Books
  WHERE Title = @Title';

EXEC sp_executesql
    @SQL,
    N'@Title VARCHAR(100)',
    @Title = 'SQL Fundamentals';
```

# Dynamic SQL vs Static SQL

| Feature          | Static SQL | Dynamic SQL |
| ---------------- | ---------- | ----------- |
| Fixed Query      | Yes        | No          |
| Flexible Filters | Limited    | Yes         |
| Dynamic Tables   | No         | Yes         |
| Dynamic Columns  | No         | Yes         |
| Security Risk    | Lower      | Higher      |

---

# Example: Safe Dynamic Procedure

```sql id="ds037"
CREATE PROCEDURE GetBooksByCategory
    @CategoryID INT
AS
BEGIN

    DECLARE @SQL NVARCHAR(MAX);

    SET @SQL =
    N'SELECT *
      FROM Books
      WHERE CategoryID = @CategoryID';

    EXEC sp_executesql
        @SQL,
        N'@CategoryID INT',
        @CategoryID;

END;
```
