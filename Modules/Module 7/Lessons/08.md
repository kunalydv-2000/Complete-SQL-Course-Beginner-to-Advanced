# What is an Output Parameter?

An Output Parameter is a variable that returns a value from a Stored Procedure to the calling program or SQL script.

---

# Visual Representation

```text id="op005"
Input Value
      ↓
Stored Procedure
      ↓
Process Data
      ↓
Return Output Value
```

---

# Basic Syntax

```sql id="op006"
CREATE PROCEDURE ProcedureName
    @OutputVariable DataType OUTPUT
AS
BEGIN

    SET @OutputVariable = Value;

END;
```

---

# Example 1: Total Books KPI

Business Requirement:

```text id="op007"
Return Total Number Of Books
```

---

Procedure:

```sql id="op008"
CREATE PROCEDURE GetTotalBooks
    @TotalBooks INT OUTPUT
AS
BEGIN

    SELECT
        @TotalBooks = COUNT(*)
    FROM Books;

END;
```

---

Execute:

```sql id="op009"
DECLARE @BookCount INT;

EXEC GetTotalBooks
    @TotalBooks = @BookCount OUTPUT;

SELECT @BookCount AS TotalBooks;
```

---

Result

| TotalBooks |
| ---------- |
| 150        |

# Example 4: Borrow Count By Member

```sql id="op015"
CREATE PROCEDURE GetBorrowCount
    @MemberID INT,
    @BorrowCount INT OUTPUT
AS
BEGIN

    SELECT
        @BorrowCount = COUNT(*)
    FROM BorrowRecords
    WHERE MemberID = @MemberID;

END;
```

---

Execute:

```sql id="op016"
DECLARE @Count INT;

EXEC GetBorrowCount
    @MemberID = 5,
    @BorrowCount = @Count OUTPUT;

SELECT @Count;
```

# Example 6: Inventory Statistics

```sql id="op018"
CREATE PROCEDURE GetInventoryStats
    @TotalBooks INT OUTPUT,
    @AveragePrice DECIMAL(10,2) OUTPUT
AS
BEGIN

    SELECT
        @TotalBooks = COUNT(*),
        @AveragePrice = AVG(BookPrice)
    FROM Books;

END;
```

---

Execute:

```sql id="op019"
DECLARE
    @Books INT,
    @AvgPrice DECIMAL(10,2);

EXEC GetInventoryStats
    @TotalBooks = @Books OUTPUT,
    @AveragePrice = @AvgPrice OUTPUT;

SELECT
    @Books AS TotalBooks,
    @AvgPrice AS AveragePrice;
```

# Example 7: Member Information Status

```sql id="op020"
CREATE PROCEDURE CheckMemberExists
    @MemberID INT,
    @Status VARCHAR(50) OUTPUT
AS
BEGIN

    IF EXISTS
    (
        SELECT 1
        FROM Members
        WHERE MemberID = @MemberID
    )
        SET @Status = 'Member Found';
    ELSE
        SET @Status = 'Member Not Found';

END;
```

---

Execute:

```sql id="op021"
DECLARE @Result VARCHAR(50);

EXEC CheckMemberExists
    @MemberID = 10,
    @Status = @Result OUTPUT;

SELECT @Result;
```

# Common Beginner Mistakes

---

## Forgetting OUTPUT Keyword

Bad:

```sql id="op032"
@TotalBooks INT
```

---

Correct:

```sql id="op033"
@TotalBooks INT OUTPUT
```

---

## Missing OUTPUT During Execution

Bad:

```sql id="op034"
EXEC GetTotalBooks
    @TotalBooks = @Count;
```

---

Correct:

```sql id="op035"
EXEC GetTotalBooks
    @TotalBooks = @Count OUTPUT;
```

---

## Data Type Mismatch

Bad:

```sql id="op036"
VARCHAR
```

for numeric values.

---

Correct:

```sql id="op037"
INT

DECIMAL
```
