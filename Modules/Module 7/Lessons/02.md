# What is CREATE VIEW?

The CREATE VIEW statement stores a SQL query as a virtual table.

Syntax:

```sql
CREATE VIEW ViewName
AS
SELECT
    Column1,
    Column2
FROM TableName;
```

---

# Simple View

A simple view uses:

```text
One Table
```

---

# Example 1: Book List View

```sql
CREATE VIEW vw_AllBooks
AS
SELECT
    BookID,
    Title,
    BookPrice,
    PublicationYear
FROM Books;
```

Use the View:

```sql
SELECT *
FROM vw_AllBooks;
```

# Multi-Table Views

Many business reports require data from multiple tables.

---

# Example 3: Book Catalog View

Business Requirement:

```text
Display

Book Title

Category

Publisher

Price
```

---

Query:

```sql
CREATE VIEW vw_BookCatalog
AS
SELECT
    B.BookID,
    B.Title,
    C.CategoryName,
    P.PublisherName,
    B.BookPrice
FROM Books B
INNER JOIN Categories C
    ON B.CategoryID = C.CategoryID
INNER JOIN Publishers P
    ON B.PublisherID = P.PublisherID;
```

---

Using the View:

```sql
SELECT *
FROM vw_BookCatalog;
```

---

Result

| Title            | Category   | Publisher | Price |
| ---------------- | ---------- | --------- | ----- |
| SQL Fundamentals | Technology | TechBooks | 499   |

# Example 4: Active Members View

Business Requirement:

```text
Show Members
Who Borrowed Books
```

---

View:

```sql
CREATE VIEW vw_ActiveMembers
AS
SELECT DISTINCT
    M.MemberID,
    M.FirstName,
    M.LastName
FROM Members M
INNER JOIN BorrowRecords BR
    ON M.MemberID = BR.MemberID;
```

---

Use:

```sql
SELECT *
FROM vw_ActiveMembers;
```

---

# Example 5: Reserved Books View

```sql
CREATE VIEW vw_ReservedBooks
AS
SELECT DISTINCT
    B.BookID,
    B.Title
FROM Books B
INNER JOIN Reservations R
    ON B.BookID = R.BookID;
```

# Example 6: Publisher Performance View

```sql
CREATE VIEW vw_PublisherPerformance
AS
SELECT
    P.PublisherName,
    COUNT(B.BookID) AS TotalBooks
FROM Publishers P
LEFT JOIN Books B
    ON P.PublisherID = B.PublisherID
GROUP BY P.PublisherName;
```

---

Use:

```sql
SELECT *
FROM vw_PublisherPerformance;
```

---

# Example 7: Category Statistics View

```sql
CREATE VIEW vw_CategoryStatistics
AS
SELECT
    C.CategoryName,
    COUNT(B.BookID) AS TotalBooks,
    AVG(B.BookPrice) AS AveragePrice
FROM Categories C
LEFT JOIN Books B
    ON C.CategoryID = B.CategoryID
GROUP BY C.CategoryName;
```

---

# Example 8: Inventory Dashboard View

```sql
CREATE VIEW vw_InventorySummary
AS
SELECT
    COUNT(*) AS TotalBooks,
    SUM(BookPrice) AS InventoryValue,
    AVG(BookPrice) AS AveragePrice,
    MAX(BookPrice) AS HighestPrice,
    MIN(BookPrice) AS LowestPrice
FROM Books;
```

---

Query:

```sql
SELECT *
FROM vw_InventorySummary;
```

# Common Beginner Mistakes

---

## Missing AS

Incorrect:

```sql
CREATE VIEW vw_Books
SELECT *
FROM Books;
```

---

Correct:

```sql
CREATE VIEW vw_Books
AS
SELECT *
FROM Books;
```

---

## Duplicate View Names

Each View must have:

```text
Unique Name
```

---

## Using SELECT *

Bad:

```sql
CREATE VIEW vw_Books
AS
SELECT *
FROM Books;
```

---

Better:

```sql
SELECT
    BookID,
    Title,
    BookPrice
```

---

## Creating Unnecessary Views

Only create Views that provide value.
