
# Example 1: Create a Simple Procedure

Business Requirement:

```text id="csp006"
Display all books.
```

---

Procedure:

```sql id="csp007"
CREATE PROCEDURE GetAllBooks
AS
BEGIN

    SELECT
        BookID,
        Title,
        BookPrice
    FROM Books;

END;
```

---

Execute:

```sql id="csp008"
EXEC GetAllBooks;
```

# Example 3: Book Catalog Procedure

Business Requirement:

```text id="csp011"
Display book details with category and publisher.
```

---

Procedure:

```sql id="csp012"
CREATE PROCEDURE GetBookCatalog
AS
BEGIN

    SELECT
        B.BookID,
        B.Title,
        C.CategoryName,
        P.PublisherName,
        B.BookPrice
    FROM Books B
    INNER JOIN Categories C
        ON B.CategoryID = C.CategoryID
    INNER JOIN Publishers P
        ON B.PublisherID = P.PublisherID;

END;
```

---

Execute:

```sql id="csp013"
EXEC GetBookCatalog;
```

# Example 4: Active Members Procedure

```sql id="csp014"
CREATE PROCEDURE GetActiveMembers
AS
BEGIN

    SELECT DISTINCT
        M.MemberID,
        M.FirstName,
        M.LastName
    FROM Members M
    INNER JOIN BorrowRecords BR
        ON M.MemberID = BR.MemberID;

END;
```

# Example 5: Inventory Report Procedure

```sql id="csp015"
CREATE PROCEDURE GetInventoryReport
AS
BEGIN

    SELECT
        COUNT(*) AS TotalBooks,
        SUM(BookPrice) AS InventoryValue,
        AVG(BookPrice) AS AveragePrice,
        MAX(BookPrice) AS HighestPrice,
        MIN(BookPrice) AS LowestPrice
    FROM Books;

END;
```

---

Execute:

```sql id="csp016"
EXEC GetInventoryReport;
```

# Example 6: Modify Procedure

Original:

```sql id="csp026"
CREATE PROCEDURE GetAllBooks
AS
BEGIN

    SELECT
        BookID,
```

# Example 7: KPI Procedure

```sql id="csp033"
CREATE PROCEDURE GetLibraryKPIs
AS
BEGIN

    SELECT
        (SELECT COUNT(*) FROM Books) AS TotalBooks,
        (SELECT COUNT(*) FROM Members) AS TotalMembers,
        (SELECT COUNT(*) FROM Authors) AS TotalAuthors,
        (SELECT COUNT(*) FROM BorrowRecords) AS TotalBorrows;

END;
```

# Example 8: Publisher Report Procedure

```sql id="csp035"
CREATE PROCEDURE GetPublisherPerformance
AS
BEGIN

    SELECT
        P.PublisherName,
        COUNT(B.BookID) AS TotalBooks
    FROM Publishers P
    LEFT JOIN Books B
        ON P.PublisherID = B.PublisherID
    GROUP BY P.PublisherName
    ORDER BY TotalBooks DESC;

END;
```

# Common Beginner Mistakes

---

## Forgetting BEGIN END

Bad:

```sql id="csp043"
CREATE PROCEDURE GetBooks
AS
SELECT *
FROM Books;
```

---

Better:

```sql id="csp044"
CREATE PROCEDURE GetBooks
AS
BEGIN

    SELECT *
    FROM Books;

END;
```

---

## Poor Naming

Bad:

```text id="csp045"
Proc1
```

---

Better:

```text id="csp046"
GetAllBooks
```

---

## Deleting Procedures Without Checks

Always review dependencies.

---

## Mixing Multiple Business Purposes

Bad:

```text id="csp047"
Books

Members

Reservations

All In One Procedure
```

---

Better:

```text id="csp048"
One Purpose Per Procedure
```
