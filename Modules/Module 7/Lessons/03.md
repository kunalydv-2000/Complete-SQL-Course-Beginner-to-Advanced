# Why Modify Views?

Imagine this View:

```sql
CREATE VIEW vw_AllBooks
AS
SELECT
    BookID,
    Title,
    BookPrice
FROM Books;
```

Management later requests:

```text
Publication Year
```

Instead of deleting and recreating the View, you can modify it.

---

# ALTER VIEW

Used to update an existing View.

---

# Syntax

```sql
ALTER VIEW ViewName
AS
SELECT ...
```

---

# Example 1: Modify Book View

Original View:

```sql
CREATE VIEW vw_AllBooks
AS
SELECT
    BookID,
    Title,
    BookPrice
FROM Books;
```

---

Updated Version:

```sql
ALTER VIEW vw_AllBooks
AS
SELECT
    BookID,
    Title,
    BookPrice,
    PublicationYear
FROM Books;
```

---

Now:

```sql
SELECT *
FROM vw_AllBooks;
```

returns the additional column.

---

# How ALTER VIEW Works

```text
Existing View
       ↓
ALTER VIEW
       ↓
New Definition
       ↓
Updated Results
```

---

# Example 2: Update Book Catalog View

Original:

```sql
CREATE VIEW vw_BookCatalog
AS
SELECT
    B.Title,
    C.CategoryName
FROM Books B
INNER JOIN Categories C
    ON B.CategoryID = C.CategoryID;
```

---

New Requirement:

```text
Add Publisher Information
```

---

Updated View:

```sql
ALTER VIEW vw_BookCatalog
AS
SELECT
    B.Title,
    C.CategoryName,
    P.PublisherName,
    B.BookPrice
FROM Books B
INNER JOIN Categories C
    ON B.CategoryID = C.CategoryID
INNER JOIN Publishers P
    ON B.PublisherID = P.PublisherID;
```

---

# Renaming a View

SQL Server allows:

```sql
sp_rename
```

---

Example:

```sql
EXEC sp_rename
'vw_AllBooks',
'vw_Books';
```

---

Best Practice:

```text
Avoid frequent renaming
```

because dependent reports may fail.

---

Used to permanently remove a View.

---

---

Before removing a View:

# Example 4: Updating Reporting View

Original:

```sql
CREATE VIEW vw_PublisherPerformance
AS
SELECT
    PublisherName
FROM Publishers;
```

---

Improved Version:

```sql
ALTER VIEW vw_PublisherPerformance
AS
SELECT
    P.PublisherName,
    COUNT(B.BookID) AS TotalBooks
FROM Publishers P
LEFT JOIN Books B
    ON P.PublisherID = B.PublisherID
GROUP BY P.PublisherName;
```

# Common Beginner Mistakes

---

## Dropping Views Accidentally

Bad:

```sql
DROP VIEW vw_BookCatalog;
```

---

## Forgetting Dependencies

Reports may stop working.

---

Unnecessary:

```sql

```

```sql
ALTER VIEW
```

## No Backup

Always save View definitions.
