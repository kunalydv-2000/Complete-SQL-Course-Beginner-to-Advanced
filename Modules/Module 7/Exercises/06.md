# Exercise 06: Creating Stored Procedures

## Objective

Practice creating, executing, modifying, inspecting, and deleting Stored Procedures while following professional SQL Server development practices.

---

# Scenario

The Library Management System requires reusable database programs to support:

* Reporting
* Dashboards
* Analytics
* Inventory Management

As a database developer, your task is to create and manage Stored Procedures that automate business operations.

---

# Exercise 1: Create Your First Procedure

Create the following procedure:

```sql
CREATE PROCEDURE GetAllBooks
AS
BEGIN

    SELECT
        BookID,
        Title,
        BookPrice
    FROM Books;

END;
```

---

Execute:

```sql
EXEC GetAllBooks;
```

---

Questions:

### Question 1

What is the procedure name?

### Question 2

Which table is queried?

### Question 3

Which columns are returned?
