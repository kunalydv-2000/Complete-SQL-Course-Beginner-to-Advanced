# Exercise 09: Dynamic SQL

## Objective

Practice building and executing Dynamic SQL using `EXEC()` and `sp_executesql`, while understanding flexibility, security considerations, and business applications.

---

# Scenario

The Library Management System requires flexible reporting capabilities.

Management wants users to:

* Search books dynamically
* Filter records based on user input
* Generate customizable reports
* Sort results dynamically

Instead of creating separate procedures for every requirement, Dynamic SQL will be used.

---
