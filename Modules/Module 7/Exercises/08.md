# Exercise 08: Output Parameters

## Objective

Practice creating Stored Procedures that return values using OUTPUT parameters for KPI reporting, validation checks, status messages, and business analytics.

---

# Scenario

The Library Management System management team needs KPI metrics and status information that can be returned directly from Stored Procedures.

Instead of returning full result sets, procedures should return:

* Total Books
* Total Members
* Average Book Price
* Reservation Counts
* Borrow Counts
* Validation Messages

Your task is to create and use OUTPUT parameters.

---

# Exercise 1: Total Books KPI

Create:

```text
GetTotalBooks
```

---

Output Parameter:

```sql
@TotalBooks INT OUTPUT
```

---

Requirements:

Return:

```text
Total Number Of Books
```

---

Execute:

```sql
DECLARE @BookCount INT;

EXEC GetTotalBooks
    @TotalBooks = @BookCount OUTPUT;

SELECT @BookCount AS TotalBooks;
```

---

Questions:

### Question 1

What value is returned?

### Question 2

Which aggregate function is used?

### Question 3

Why use an OUTPUT parameter instead of a full result set?
