# Exercise 07: Input Parameters

## Objective

Practice creating Stored Procedures that accept input parameters, perform dynamic filtering, validate inputs, and generate flexible business reports.

---

# Scenario

The Library Management System currently contains procedures that return all records.

Management now wants users to retrieve:

* Books by Category
* Books by Publisher
* Members by ID
* Reservations by Member
* Borrow History by Member

Instead of creating separate procedures for every possible value, you will use Input Parameters.

---

# Exercise 1: Books by Category

Create a procedure:

```text

```

---

Input Parameter:

```sql

```

---

Requirements:

Display:

```text

Title

BookPrice
```

---

Execute:

```sql

    @CategoryID = 1;
```

Which rows are returned?

Price <= MaxPrice
