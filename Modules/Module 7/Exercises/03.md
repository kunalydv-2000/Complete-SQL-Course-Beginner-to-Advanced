# Exercise 03: Updating and Managing Views

## Objective

Practice modifying, inspecting, maintaining, and removing SQL Views using professional database administration techniques.

---

# Scenario

The Library Management System already contains several Views used by reports and dashboards.

Business requirements have changed and the database team must:

* Modify existing Views
* Review View definitions
* Refresh metadata
* Manage dependencies
* Remove obsolete Views

Your task is to maintain these Views professionally.

---

# Exercise 1: Create a Basic View

Create the following View:

```sql
CREATE VIEW vw_AllBooks
AS
SELECT
    BookID,
    Title
FROM Books;
```

---

Execute:

```sql
SELECT *
FROM vw_AllBooks;
```

---

Questions:

1. How many columns are returned?
2. What information is missing?
