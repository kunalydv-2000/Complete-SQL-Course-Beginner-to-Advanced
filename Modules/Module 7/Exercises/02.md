# Exercise 02: Creating Views

## Objective

Practice creating simple Views, multi-table Views, and reporting Views using the Library Management System database.

---

# Scenario

The library management team wants reusable database objects that simplify reporting.

Instead of writing complex queries repeatedly, they want Views that can be used by analysts, developers, and reporting tools.

Your task is to create various Views based on business requirements.

---

# Exercise 1: Create a Simple View

Create a View named:

```text
vw_Books
```

Requirements:

Display:

* BookID
* Title
* BookPrice
* PublicationYear

---

After creating the View, execute:

```sql
SELECT *
FROM vw_Books;
```

# Exercise 9: Test All Views

```sql

SELECT * FROM vw_Members;

SELECT * FROM vw_BookCatalog;

SELECT * FROM vw_ActiveMembers;

SELECT * FROM vw_ReservedBooks;

SELECT * FROM vw_PublisherPerformance;

SELECT * FROM vw_CategoryStatistics;

```

---

Answer:

1. Which View returns the most rows?
2. Which View returns aggregated data?
3. Which View uses multiple tables?
