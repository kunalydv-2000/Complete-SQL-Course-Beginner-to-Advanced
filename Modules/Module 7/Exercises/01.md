# Exercise 01: Introduction to Views

## Objective

Practice understanding SQL Views, virtual tables, and their business applications.

---

# Scenario

The library management team frequently requests a list of books and members.

Instead of repeatedly writing the same queries, the database team wants to use Views.

Your task is to understand how Views simplify reporting and data access.

# Exercise 2: Analyze the Query

Review the query below:

```sql
SELECT
    BookID,
    Title,
    BookPrice
FROM Books;
```

Answer:

1. Which table is used?
2. Which columns are returned?
3. Could this query become a View?

# Exercise 3: Create Your First View

