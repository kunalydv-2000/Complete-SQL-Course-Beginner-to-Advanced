# Introduction

In previous lessons, you learned how to:

* Create databases
* Create tables
* Apply constraints

However, an empty table has little value.

To make a database useful, we must populate it with data.

SQL Server uses the **INSERT INTO** statement to add records to tables.

---

# What is INSERT?

The INSERT statement adds new rows to a table.

Think of it as:

```text id="ins001"
Table
   +
New Record
   =
Updated Table
```

---

# Example Table

### Students

| StudentID | FirstName |
| --------- | --------- |
| 1         | John      |
| 2         | Sarah     |

Adding a new student:

| StudentID | FirstName |
| --------- | --------- |
| 1         | John      |
| 2         | Sarah     |
| 3         | David     |

---

# INSERT INTO Syntax

Basic syntax:

```sql id="ins002"
INSERT INTO TableName
VALUES (...);
```

---

# Example

```sql id="ins003"
INSERT INTO Students
VALUES (1, 'John');
```

---

# Understanding the Statement

```sql id="ins004"
INSERT INTO Students
VALUES (1, 'John');
```

Means:

```text id="ins005"
StudentID = 1
FirstName = John
```

# Inserting Multiple Rows

Instead of multiple INSERT statements, SQL Server allows multiple rows in one statement.

---

# Example

```sql id="ins011"

VALUES
(4, 'Emma'),
(5, 'James'),
(6, 'Sophia');
```

# Benefits

✅ Faster execution

✅ Cleaner code

✅ Better performance

# Inserting into Specific Columns

Recommended approach.

---

# Syntax

```sql id="ins012"
INSERT INTO TableName
(Column1, Column2)
VALUES
(Value1, Value2);
```

---

# Example

```sql id="ins013"
INSERT INTO Students
(StudentID, FirstName)
VALUES
(7, 'Michael');
```

---

# Why Specify Columns?

Advantages:

* More readable
* Safer
* Flexible
* Prevents column order issues

# Common INSERT Errors

---

## Incorrect Number of Values

Bad:

```sql id="ins030"
INSERT INTO Students
VALUES (1);
```

Table expects more columns.

---

# Column Mismatch

Bad:

```sql id="ins031"
INSERT INTO Students
VALUES ('John', 1);
```

Wrong order.

---

# Data Type Mismatch

Bad:

```sql id="ins032"
INSERT INTO Students
VALUES ('ABC', 'John');
```

If StudentID is INT, SQL Server throws an error.

---

# Violating Constraints

Example:

```sql id="ins033"
INSERT INTO Users
VALUES
(1, 'john@email.com');
```

---

Attempt:

```sql id="ins034"
INSERT INTO Users
VALUES
(1, 'john@email.com');
```

Duplicate PRIMARY KEY or UNIQUE value.

Insert fails.

---

# Best Practices

---
