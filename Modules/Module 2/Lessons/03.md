# Introduction

A database by itself cannot store information.

To store data, we need **tables**.

Tables are the primary structures used to organize information in relational databases.

Every application you use relies on tables.

Examples:

* Customer tables
* Product tables
* Employee tables
* Order tables

In this lesson, you'll learn how to create and manage tables using SQL Server.

---

# What is a Table?

A table is a collection of related data organized into rows and columns.

Example:

| CustomerID | FirstName | LastName |
| ---------- | --------- | -------- |
| 1          | John      | Smith    |
| 2          | Sarah     | Wilson   |

---

# Components of a Table

```text id="table001"
Table
│
├── Columns
├── Rows
└── Constraints
```

---

## Columns

Columns define the type of information stored.

Example:

```text id="table002"
CustomerID
FirstName
LastName
Email
```

---

## Rows

Rows contain actual records.

Example:

| CustomerID | FirstName |
| ---------- | --------- |
| 1          | John      |

One row = One record.

---

# Why Tables Are Important

Tables help:

✅ Organize data

✅ Reduce redundancy

✅ Improve performance

✅ Maintain consistency

✅ Support relationships

# Best Practices

### Use Meaningful Names

Good:

```text id="table017"
BorrowRecords
```

Bad:

```text id="table018"
BR
```

---

### Avoid Spaces

Bad:

```text id="table019"
Customer Details
```

Good:

```text id="table020"
CustomerDetails
```

---

### Be Consistent

Choose one style.

Examples:

```text id="table021"
PascalCase
```

or

```text id="table022"
snake_case
```

# Common Table Design Mistakes

---

## Using Generic Names

Bad:

```sql id="table028"
CREATE TABLE Data (
    Field1 VARCHAR(100)
);
```

---

Good:

```sql id="table029"
CREATE TABLE Customers (
    CustomerName VARCHAR(100)
);
```

---

## Choosing Incorrect Data Types

Bad:

```sql id="table030"
Age VARCHAR(20)
```

---

Good:

```sql id="table031"
Age INT
```

---

## Too Few Columns

Bad:

```sql id="table032"
CREATE TABLE Employees (
    Name VARCHAR(100)
);
```

Missing important information.

---

Better:

```sql id="table033"
CREATE TABLE Employees (
    EmployeeID INT,
    FirstName VARCHAR(100),
    LastName VARCHAR(100),
    Email VARCHAR(255),
    HireDate DATE
);
```
