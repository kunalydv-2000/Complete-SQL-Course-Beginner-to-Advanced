# Introduction

Data in a database rarely stays the same forever.

Customers change addresses.

Employees receive salary increases.

Products change prices.

Students update their contact information.

To modify existing data, SQL Server provides the **UPDATE** statement.

---

# What is UPDATE?

The UPDATE statement modifies existing records in a table.

Think of it as:

```text id="upd001"
Existing Record
       ↓
Modify Values
       ↓
Updated Record
```

---

# Example Table

### Students

| StudentID | FirstName |
| --------- | --------- |
| 1         | John      |
| 2         | Sarah     |

Suppose John changes his name to Johnny.

---

Before:

| StudentID | FirstName |
| --------- | --------- |
| 1         | John      |

After:

| StudentID | FirstName |
| --------- | --------- |
| 1         | Johnny    |

# UPDATE Syntax

Basic syntax:

```sql id="upd002"
UPDATE TableName
SET ColumnName = Value
WHERE Condition;
```

---

# Understanding the Statement

```sql id="upd003"
UPDATE Students
SET FirstName = 'Johnny'
WHERE StudentID = 1;
```

Meaning:

```text id="upd004"
Find StudentID = 1
Update FirstName
Save Changes
```

---


# Why WHERE is Important

The WHERE clause determines which rows are updated.

Without WHERE:

```sql id="upd009"
UPDATE Students
SET FirstName = 'Johnny';
```

---

Result:

| StudentID | FirstName |
| --------- | --------- |
| 1         | Johnny    |
| 2         | Johnny    |
| 3         | Johnny    |

Every row is updated.

# Updating Multiple Rows

The WHERE clause can target multiple rows.

---

# Example

```sql id="upd015"
UPDATE Employees
SET Salary = 50000
WHERE DepartmentID = 3;
```

All employees in Department 3 are updated.

---

# Using Comparison Operators

---

## Greater Than

```sql id="upd016"
UPDATE Products
SET Price = 100
WHERE StockQuantity > 50;
```

---

## Less Than

```sql id="upd017"
UPDATE Employees
SET Salary = 30000
WHERE Age < 25;
```

## Not Equal

```sql id="upd018"

WHERE Status <> 'Inactive';
```

# Common UPDATE Mistakes

---

## Missing WHERE Clause

Bad:

```sql id="upd029"
UPDATE Students
SET FirstName = 'Test';
```

Updates every row.

---

## Wrong Condition

Bad:

```sql id="upd030"
UPDATE Students
SET FirstName = 'John'
WHERE StudentID = 100;
```

No matching row.

Nothing changes.

---

## Wrong Data Type

Bad:

```sql id="upd031"
UPDATE Students
SET StudentID = 'ABC';
```

Error if StudentID is INT.

---

## Updating Primary Keys

Avoid:

```sql id="upd032"
UPDATE Students
SET StudentID = 999
WHERE StudentID = 1;
```

Can break relationships.
