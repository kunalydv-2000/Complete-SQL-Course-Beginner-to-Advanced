# Exercise 02: SUM() and AVG() Functions

## Objective

Practice calculating totals and averages using SUM() and AVG().

---

# Database

```sql
USE LibraryManagementSystem;
GO
```

---

# Tasks

### Task 1

Calculate total value of all books.

Expected Output:

```text
TotalBookValue
```

---

### Task 2

Calculate average book price.

Expected Output:

```text
AverageBookPrice
```

---

### Task 3

Calculate total fines collected.

Expected Output:

```text
TotalFineAmount
```

---

### Task 4

Calculate average fine amount.

Expected Output:

```text
AverageFineAmount
```

---

### Task 5

Calculate average price of books published after 2015.

Expected Output:

```text
AverageRecentBookPrice
```

---

### Challenge

Create one query that returns:

```text
TotalBooks
AverageBookPrice
OldestPublicationYear
NewestPublicationYear
```

---

# Success Criteria

✅ Uses SUM()

✅ Uses AVG()

✅ Uses aliases
