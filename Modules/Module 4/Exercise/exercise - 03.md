# Exercise 03: MIN() and MAX() Functions

## Objective

Practice finding minimum and maximum values from business data.

---

# Database

```sql
USE LibraryManagementSystem;
GO
```

---

# Tasks

### Task 1

Find the oldest publication year.

Expected Output:

```text
OldestPublicationYear
```

---

### Task 2

Find the newest publication year.

Expected Output:

```text
NewestPublicationYear
```

---

### Task 3

Find earliest membership date.

Expected Output:

```text
EarliestMembershipDate
```

---

### Task 4

Find latest membership date.

Expected Output:

```text
LatestMembershipDate
```

---

### Task 5

Find highest fine amount.

Expected Output:

```text
HighestFineAmount
```

---

### Task 6

Find lowest fine amount.

Expected Output:

```text
LowestFineAmount
```

---

### Challenge

Create a query that returns:

```text
OldestBookYear
NewestBookYear
EarliestMembership
LatestMembership
```

in a single result.
