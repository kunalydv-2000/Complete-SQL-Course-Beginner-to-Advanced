# Exercise 01: COUNT() Function

## Objective

Practice using COUNT() to count records, non-null values, and unique values.

---

# Database

```sql
USE LibraryManagementSystem;
GO
```

---

# Tasks

### Task 1

Count total books.

Expected Output:

```text
TotalBooks
```

---

### Task 2

Count total members.

Expected Output:

```text
TotalMembers
```

---

### Task 3

Count total authors.

Expected Output:

```text
TotalAuthors
```

---

### Task 4

Count total reservations.

Expected Output:

```text
TotalReservations
```

---

### Task 5

Count distinct categories used by books.

Expected Output:

```text
UniqueCategories
```

---

### Challenge

Count books published after 2020.

---

# Success Criteria

✅ Uses COUNT(*)

✅ Uses COUNT(DISTINCT)
